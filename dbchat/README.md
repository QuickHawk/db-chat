# DBChat - Generative UI Proof of Concept

This project is a Proof of Concept for a "Generative UI" application. It allows a user to connect to a database and ask questions in natural language. The backend agent analyzes the request and generates a dynamic UI configuration, which the frontend then renders in real-time.

This version uses a real Large Language Model (Google's Gemini) to power the agent.

## Project Structure

-   `backend/`: Contains the Python FastAPI server, the natural language agent, and database connection logic.
-   `frontend/`: Contains the React application that handles user input and dynamically renders the UI based on the backend's response.

---

## How to Run This Project

### Prerequisites

-   Python 3.10+
-   Node.js and npm
-   A Google API Key for Gemini

### 1. Backend Setup

First, set up and run the Python backend server.

```bash
# Navigate to the backend directory
cd dbchat/backend

# Create a .env file and add your Google API key
echo "GOOGLE_API_KEY='your_api_key_here'" > .env

# Create a virtual environment
python3 -m venv .venv
source .venv/bin/activate

# Install dependencies
pip install -r requirements.txt

# The repository does not have a requirements.txt, so let's install them manually
pip install fastapi uvicorn[standard] langchain langchain-community sqlalchemy google-generativeai langchain-google-genai python-dotenv

# Create the sample database for testing
python3 create_sample_db.py

# Run the backend server
uvicorn main:app --host 127.0.0.1 --port 8000
```

The backend server will be running at `http://127.0.0.1:8000`.

**NOTE:** Some environments may experience instability with the `google-generativeai` dependencies, causing the server to crash.

### 2. Frontend Setup

In a new terminal, set up and run the React frontend.

```bash
# Navigate to the frontend directory
cd dbchat/frontend

# Install dependencies
npm install

# Run the frontend development server
npm run dev
```

The frontend will be available at `http://localhost:5173`.

### 3. Using the Application

1.  **Open your browser** to the frontend URL (e.g., `http://localhost:5173`).
2.  **Connect to the database.** In the input field, provide the path to the sample database: `sample_data.db`.
3.  **Click "Connect".**
4.  **Ask a question.** You can now ask complex questions in natural language, for example:
    *   `What is the total of all story points?`
    *   `Show me a breakdown of expenses by category this month.`
    *   `Which were the top 3 most expensive items?`
5.  **View the dynamic UI.** The frontend will render a UI with charts and cards generated by the LLM.
